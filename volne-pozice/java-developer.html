O pozici

Pro naše klienta — stabilní IT společnost — hledáme zkušeného JAVA Developera. Jedná se o zajímavou pozici s perspektivou, moderními technologiemi a motivujícím ohodnocením.

Náplň práce

  • Vývoj a správa Java/J2EE aplikací
  • Analýza a implementace business požadavků

  • Code review a testování

Požadujeme

  • Zkušenosti s Java / J2EE / OOP (min. 3 roky)

Nabízíme

  • Zajímavé projekty a moderní technologie
  • Motivující ohodnocení 4–5 000 CZK/man-day

  • Přátelský tým a dobré zázemí
